## E-Commerce Sales & Order Performance Dashboard

## Project Overview

This project focuses on analyzing e-commerce sales and order performance using Tableau. An interactive dashboard was developed to explore sales trends, product performance, shipping efficiency, customer order patterns, and geographic sales distribution.

The objective of this project is to transform raw sales data into meaningful business insights and support data-driven decision-making.

## Tools and Technologies

- Tableau
- CSV Dataset
- Data Visualization
- Exploratory Data Analysis (EDA)
- Business Intelligence (BI)

## Key Performance Indicators (KPIs)

- **Total Sales Amount:** ₹78,592,678
- **Total Quantity:** 116,649 units
- **Total Products:** 7,190
- **Product Categories:** 9
- **Product Sizes:** 11
- **Shipped Quantity:** 94.21%

## Dashboard Features

- Weekly sales and quantity trends
- Product category performance analysis
- Order and courier status analysis
- Sales channel distribution
- B2B and non-B2B sales analysis
- Top 10 states by order quantity
- Geographic sales distribution using an interactive map
- Product size distribution
- Interactive category filters

## Key Findings

- The recorded sales amount reached approximately ₹78.59 million.
- Approximately 94.21% of the total quantity was classified as shipped, while 5.79% was unshipped.
- Maharashtra recorded the highest quantity among the states displayed.
- Non-B2B transactions accounted for 99.28% of the total quantity.
- Weekly sales and order quantities fluctuated throughout the reporting period.
